## 🔦 Animated Lamp

A desk lamp you can toggle by clicking it or pulling the cord. Choose the glow colour from 8 presets or a custom color picker — the lamp shade and light beam both change to match.

**Features:** Pull-cord animation · 8 color swatches · custom color input · glow beam · burst flash · spacebar shortcut

---

## ⏳ Anime Loading

A page loading screen inspired by anime aesthetics. No GIF — pure CSS animations only.

**Features:** Dual counter-rotating rings · gradient kanji center · bouncing dots · animated progress bar · floating particles

---

## 🚫 Page Error (404)

A modern 404 error page with glitch typography and a sci-fi feel.

**Features:** Glitch text animation · CSS scanline · dot-grid background · glowing orbs · floating geometric particles · "Go back" button

---

## 🎆 Fireworks

A full canvas fireworks engine you can control in real-time.

**Features:** 6 explosion types (chrysanthemum, willow, ring, palm, fountain, burst) · WebAudio synth sounds · click-to-fire · auto-launch rate · gravity/wind/trail controls · snapshot & screen recording
